# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We expect participants to be respectful and constructive in issues, pull
requests, reviews, and other project spaces. Harassment, threats, personal
attacks, and publication of another person's private information are not
acceptable.

Maintainers may edit or remove contributions and restrict participation when
these expectations are violated. To report a conduct concern privately, use the
[private reporting form](https://github.com/Nettechnologys/plombir-git/security/advisories/new)
and mark it as a conduct report. Maintainers will limit access to the report,
review it fairly, and avoid public disclosure of the reporter's identity.
