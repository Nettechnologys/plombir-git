# Plombir Git v0.1.0

First tagged release of the server, runner, and MCP stdio binary. The release
contains Linux x86_64 and aarch64 binary archives with the built web UI, an SPDX JSON image SBOM for
each architecture, a source dependency SBOM (which also includes build and dev
dependencies), and a multi-architecture image in GHCR. The image and binary
archives have GitHub build provenance attestations.

## Upgrade and rollback

Back up the database **and** repository storage before upgrading. File-backed
SQLite migrations run while the server is stopped; see the offline migration
procedure in `deploy/README.md`. Check the migration path before switching the
image, and test a restore before relying on rollback: an older binary may not
understand a database migrated by a newer one. Pin the image by digest for a
repeatable deployment; the moving `latest` tag is not a rollback reference.

The standalone binaries are linked against the Debian bookworm runtime used by
the image. For a host with different system libraries, run the published image.
