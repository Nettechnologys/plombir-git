# Security policy

## Supported versions

Security fixes are developed for the current release line. Older releases may
need to upgrade to receive a fix. See [Releases](https://github.com/Nettechnologys/plombir-git/releases)
for the latest published version.

## Report a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/Nettechnologys/plombir-git/security/advisories/new).
Do not open a public issue or pull request containing an undisclosed exploit,
credentials, or sensitive instance data.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. The maintainers aim to acknowledge reports within five business
days, coordinate a fix and disclosure date with the reporter, and publish an
advisory when users need to act. This is a response target, not a guaranteed
resolution deadline. If the private reporting form is unavailable, contact a
repository maintainer through their GitHub profile to arrange a private channel
before sending details.

Publicly documented and already fixed findings may be discussed in issues;
please verify the affected version first.
